DriveGuard – Driver Safety and Drowsiness Detection System

📌 Project Overview

DriveGuard is a driver safety system designed to help prevent road accidents caused by driver drowsiness and fatigue. It provides a user-friendly interface for monitoring driver alertness, tracking journeys, and displaying safety alerts.

This repository contains the source code for the DriveGuard prototype, initially designed using Figma Make.

🎯 Objectives

Detect driver drowsiness and monitor eye-state activity.

Provide real-time driver status and safety alerts.

Monitor journey progress from source to destination.

Display route information, estimated distance, and travel time.

Identify critical stops and provide safety recommendations.

✨ Key Features

Driver Dashboard: Displays current driver status and journey information.

Drowsiness Monitoring: Shows eye-state activity and driver alertness status.

Safety Alerts: Displays warnings when drowsiness is detected.

Journey Management: Supports starting and ending journeys.

Route Planning: Displays source, destination, route, and estimated travel details.

Critical Stops: Helps identify suitable stopping points for driver safety.

Safety Recommendations: Provides guidance based on the driver's status.
